# 🌐 CCNA Networking Lab

A hands-on collection of **Cisco Packet Tracer labs** built to demonstrate practical networking skills across switching, routing, network services, and troubleshooting.

This repository documents real lab configurations, verification outputs, Packet Tracer files, and screenshots covering topics such as:

* 🖧 VLANs and Inter-VLAN Routing
* 🔄 STP, RSTP, and VTP
* 🛣️ RIP, OSPF, and EIGRP
* 📡 DHCP and DNS
* 🔐 NAT and PAT
* 🚦 Default Routing
* 💻 Telnet
* 📶 Wireless Networking
* 🧪 Connectivity Testing and Troubleshooting

## 🎯 Lab Goal

The goal of this repository is to build and document practical **CCNA-level networking skills** using Cisco Packet Tracer and create a structured portfolio of real network configurations that can be reviewed, tested, and explained during technical interviews.

## 📂 What Each Lab Includes

Each practical may include:

* `.pkt` Packet Tracer file
* Configuration commands
* Verification output
* Connectivity testing
* Screenshots
* Lab-specific README documentation

## 🚀 Purpose

This repository serves as a practical networking portfolio showcasing hands-on experience with core Cisco networking concepts and real lab-based implementation.
