# CCNA Networking Lab

A hands-on collection of Cisco Packet Tracer labs built to demonstrate practical networking skills across switching, routing, addressing, network services, and troubleshooting.

This repository documents real lab configurations, verification outputs, Packet Tracer files, and screenshots covering topics such as:

* VLANs and Inter-VLAN Routing
* STP, RSTP, and VTP
* RIP, OSPF, and EIGRP
* DHCP and DNS
* NAT and PAT
* Default Routing
* Telnet
* Wireless Networking
* Network Connectivity Testing and Troubleshooting

Each lab includes practical configuration steps, command verification, connectivity testing, and supporting screenshots to provide clear evidence of hands-on networking practice.

## Lab Goal

The goal of this repository is to build and document practical CCNA-level networking skills using Cisco Packet Tracer and create a structured portfolio of real network configurations that can be reviewed, tested, and explained during technical interviews.
